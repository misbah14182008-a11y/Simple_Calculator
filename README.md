**Simple Calculator in C** 🧮

A beginner-friendly command-line calculator written in C. It performs basic arithmetic operations including addition, subtraction, multiplication, division, modulus, and power.

### Features

* Addition, subtraction, multiplication
* Division with zero-check
* Modulus with zero-check
* Power calculation using `pow()`
* Menu-driven program
* Input validation
* Uses functions and `switch-case`

**Language:** C
**Concepts:** Functions, Loops, Switch-Case, Conditional Statements, User Input, `math.h`
